## Grok Chat

Add Grok Chat. Ask Grok a question in the search bar and the answer streams into the side panel, with its sources and the tools Grok used. Ask follow-ups in the same conversation, start a new one with ⌘N, and find the last 50 conversations with ⌘Y. Grok can search the web and X, and can run Python in xAI's sandbox if you turn that on. The model is left to xAI's default unless you pick one in the command preferences.
